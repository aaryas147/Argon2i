02

Relevant Theory

What is Argon2?

Argon2 is a memory-hard password hashing algorithm designed to make password guessing attacks more computationally expensive.

Argon2 has three main variants: Argon2d, Argon2i and Argon2id. They differ mainly in how memory is accessed during the hashing process.

Password hashing is different from encryption. A password hash is not intended to be decrypted. During authentication, the entered password is processed again and the result is compared with the stored password hash.

Important Parameters

M

Memory Cost

Determines the amount of memory used during the hashing process. It is specified in KiB by the Argon2 implementation.

T

Time Cost

Determines the computational effort or number of passes performed by the algorithm.

P

Parallelism

Determines the number of parallel lanes used during the Argon2 computation.

Argon2 Variants

Variant General Characteristic
Argon2d Uses data-dependent memory access.
Argon2i Uses data-independent memory access and is designed with side-channel resistance in mind.
Argon2id Combines characteristics of Argon2i and Argon2d.

Assessment / Learning Check

Question 1

What is the main purpose of Argon2?

Answer: Argon2 is a memory-hard password hashing algorithm designed to make password guessing computationally expensive.

Question 2

What happens when memory cost is increased?

Answer: The hashing process requires more memory.

Question 3

What happens when time cost is increased?

Answer: The computational work generally increases, resulting in longer execution time.
